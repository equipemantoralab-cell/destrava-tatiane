# Plano Destrava Empresa

Página estática de vendas da Maphel, criada a partir da copy e identidade visual fornecidas. HTML, CSS e JavaScript, sem etapa de build.

## Checkout
Configure `checkoutUrl` em `config.js` com a URL HTTPS definitiva. Enquanto vazio, os botões exibem um aviso de inscrições em breve. Nenhum pagamento é processado pela página. Parâmetros UTM são preservados ao abrir o checkout.

## Publicação
No Netlify, conecte este repositório, selecione a branch main, deixe o comando de build vazio e use `.` como pasta de publicação. A pasta `.netlify` está ignorada no Git.

## Desenvolvimento
Execute `python -m http.server 8000` nesta pasta.
